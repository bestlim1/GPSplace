# 화면 명세 (UI 설계 보고서 → 구현용 텍스트)

원본: `docs/UI설계보고서_신서임당_임재윤서지민.pdf`. 와이어프레임 모양은 PDF 3·4장을 보고, 문구·상태·전환은 이 파일을 따른다.
상태 표기: **기본 / 로딩 / 비어 있음 / 오류 / 부분**. 문구는 그대로 쓴다.

## 공통 컴포넌트

| 컴포넌트 | 규칙 |
|---|---|
| `StatusChip` | 아이콘 + 글자. 기록 중(점) / 갱신 지연(일시정지) / 기록 안 됨(일시정지, 점선 테두리) / 전송 대기(업로드) |
| `StateBanner` | 화면 위쪽 전체 폭. 아이콘 + 원인 + 기준 시각 + (있으면) 행동 링크. 데이터는 아래에 그대로 둔다 |
| `EmptyState` | 아이콘 원 + 제목 + 이유/언제 생기는지 + (있으면) 버튼 |
| `ErrorState` | 아이콘 + 제목(무엇이 실패) + “원인: …” 상자 + 다음 행동 버튼 |
| `SkeletonList` | 실제 행 모양(번호 원·두 줄 글자) 회색 막대 |
| `DateBar` | ◀ · 날짜 칩(달력 아이콘, “10월 29일 (목) · 오늘” ▾) · ▶. 오늘이면 ▶ 비활성. 칩 누르면 S-07 |
| 지도 표기 | 경로 실선 / 기록 누락 점선 + “기록 누락” 라벨 / 출발 네모 / 체류 흰 원+번호 / 최신 위치 채운 원 + 시각 라벨 / 안전 구역 실선 원+방패 / 주의 구역 점선 원+삼각형. 경로 화면 아래에 범례 |

## S-01 시작·역할 선택 · 공통 · FR-01
- 경로: 앱 최초 실행. route `role`
- 제목 “어떻게 사용하시나요?”, 보조 “이 휴대폰에서 사용할 역할을 고르세요.”
- 카드 2개(행 전체 클릭): **보호자** “보호대상자의 위치와 이동 기록을 확인합니다” → S-02 / **보호대상자** “내 위치 기록을 연결된 보호자에게 제공합니다” → S-13
- 아래 문구 “역할은 연결을 해제하면 다시 고를 수 있습니다.”
- 선택 즉시 `users/{uid}.role` 저장(익명 로그인 후). 뒤로: 앱 종료.

## S-02 연결 요청 · 보호자 · FR-01
- route `guardian/link`. 앱바 “보호대상자 연결” + ←
- 안내: “1 보호대상자 휴대폰에서 앱을 열고 [보호대상자] 선택 / 2 아래 코드를 입력하면 동의 요청이 갑니다”
- 코드 6자리를 `482 913`처럼 3+3, “남은 시간 09:12”, “유효 10분”
- 대기 상자: 진행 표시 + “동의를 기다리는 중 / 보호대상자가 코드를 입력하고 동의하면 자동으로 넘어갑니다.”
- 하단 [새 코드 만들기] (이전 코드 `cancelled`)
- 상태
  - 로딩: 코드 자리 회색 + “연결 코드를 만드는 중”
  - 기본(완료): ✓ “연결 완료 / 보호대상자 휴대폰과 연결되었습니다. 위치 권한이 허용되면 기록이 시작됩니다.” [위치 보기 시작] → S-03, 설정 화면 스택에서 제거
  - 오류: “연결되지 않았습니다 / 원인: 보호대상자가 요청을 거부했습니다(또는 10분이 지나 코드가 만료됨) / 이 코드는 더 이상 쓸 수 없습니다.” [새 코드 만들기] [처음으로]
- 뒤로: D-04 확인 → 최초 연결이면 S-01, 재연결이면 S-03

## S-03 위치 (보호자 홈) · FR-02, FR-04, NFR-05
- route `guardian/home`, 하단 탭 [위치]. 앱바 “위치” + ⚙(→ S-12)
- 지도: 오늘 경로, 체류 번호, 최신 위치(시각 라벨), 등록 구역 원. 우측 확대·축소·내 위치 버튼
- 상태 카드: `StatusChip` + 날짜 / “최신 위치” / **“14:32 수집”** + “2분 전” (위치와 시각을 반드시 한 카드)
- 행: “오늘 체류 3곳” → 기록 탭(체류), “오늘 알림 1건” → 알림 탭 (탭 전환으로 처리)
- 상태
  - 로딩: 지도 회색 + “지도를 불러오는 중”, 카드 스켈레톤. 목표: 카드 2초, 경로 3초(NFR-02)
  - 비어 있음(첫 위치 전): “아직 받은 위치가 없습니다 / 보호대상자 휴대폰에서 첫 위치가 수집되면 지도에 표시됩니다.”
  - 비어 있음(연결 없음, FR-01 예외·NFR-04): 지도 흐리게 + “연결된 보호대상자가 없습니다 / 연결이 해제되어 위치와 기록을 볼 수 없습니다.” [보호대상자 연결하기] → S-02
  - 오류: “위치를 불러오지 못했습니다 / 원인: 서버가 응답하지 않습니다 (10초 초과)” [다시 시도] — 캐시도 없을 때만
  - 부분 · 갱신 지연(A4, `now - lastPoint.t > 5분`): 배너 “25분째 새 위치가 없습니다. 휴대폰이 꺼졌거나 인터넷이 끊겼을 수 있습니다.”, 칩 “갱신 지연”, 최신 위치 핀 점선, “25분 전”, 행 “마지막 수집 위치를 표시 중”
  - 부분 · 보호자 오프라인(NFR-03): 배너 “오프라인 · 14:32에 받아 둔 위치를 보여 줍니다. 연결되면 자동으로 새로 고칩니다”, 체류 행에 “(14:32 기준)”
  - 부분 · 상대 권한 꺼짐(FR-01 예외, `links.permission.location == "denied"`): 배너 “연결은 완료됐지만 보호대상자 휴대폰의 위치 권한이 꺼져 있어 기록되지 않습니다. 보호대상자 휴대폰에서 권한을 허용해 주세요”, 칩 “기록 안 됨”
  - 부분 · 미전송(A3, `pendingCount > 0`): 배너 “보호대상자 휴대폰에 서버 미전송 기록 있음 / 인터넷이 연결되면 빈 구간이 채워집니다”, 칩 “전송 대기”, 받은 구간까지만 경로
- 뒤로: 앱 백그라운드

## S-04 기록 – 경로 · FR-02, FR-05
- route `guardian/history?tab=path&date=`. 하단 탭 [기록], `DateBar`, 상단 탭 [경로|체류]
- 지도: 선택 날짜 전체 경로, 출발, 체류 번호, 마지막 점 시각. 범례 줄(이동 경로·기록 누락·체류·출발), “수집 08:10 ~ 18:05”, “체류 3곳”
- 상태
  - 로딩: 날짜 칩은 즉시 새 날짜, 지도만 회색 + “10월 27일 기록을 불러오는 중”
  - 비어 있음: **“기록이 없습니다”** / “10월 25일에는 수집된 위치가 없습니다.” [다른 날짜 선택] → S-07
  - 오류: “기록을 불러오지 못했습니다 / 원인: 서버가 응답하지 않습니다 (10초 초과)” [다시 시도] [날짜 바꾸기]
  - 부분 · 오프라인: “오프라인 · 이 휴대폰에 저장된 기록만 표시합니다. 연결되면 서버 기록으로 갱신” + “저장된 범위 08:10 ~ 12:40”
  - 부분 · 기록 누락: 2분 넘게 점이 없는 구간은 실선으로 잇지 않고 점선 + “기록 누락”, 아래 “기록 누락 11:05 ~ 11:40 (1구간)”
- 뒤로: S-03 (날짜·상단 탭 상태 유지)

## S-05 기록 – 체류 목록 · FR-03, FR-05

- 행(전체 클릭 → S-06): 번호 원 / **“13:40 – 14:05”** + [마지막 체류] 태그(최신 1개) / “체류 25분”. 최신이 맨 위

## S-09 알림 상세 · FR-04
- route `guardian/alert/{alertId}` (푸시 진입 가능). 앱바 = 알림 종류 + ←
- 지도: 구역 원 + 판정한 연속 위치 2개(①② + 시각)
- 항목: 구역(“집 · 안전 구역 · 200m”) / 판정(“연속 위치 2개 구역 밖”) / 판정 위치 시각 / 알림 생성
- 문구 “연속된 위치 2개가 모두 구역 밖이면 이탈로 판정합니다.” (주의 구역은 “모두 구역 안이면 진입으로 판정합니다.”) — 와이어프레임에 있던 “(FR-04)” 표기는 앱 화면에 넣지 않는다
- 뒤로: S-08 (푸시로 와도 S-08)

## S-11 구역 추가·편집 (폼) · FR-04
- route `guardian/zone/edit?zoneId=`. 앱바 × + “구역 추가”/“구역 편집”
- 지도(가운데 십자 고정, 지도를 움직여 중심 지정) + 안내 “지도를 움직여 중심을 맞추세요” + 반경 원 미리보기
- 이름(1~10자), 종류 세그먼트 [안전 구역 | 주의 구역], 반경 슬라이더 50m~2km(표시 “반경 200m”)
- 하단 [저장], 편집이면 아래 텍스트 버튼 [구역 삭제] → D-03 (주요 버튼과 24dp 이상 간격)
- 오류: 이름 비었거나 10자 초과 → 필드 테두리 굵게 + 아이콘 + “이름을 입력하세요 (1~10자)”, 다른 입력 유지, 저장 안 함
- 저장 성공 → S-10. 판정은 저장 직후부터 새 값 적용
- 뒤로/×: 키보드 열려 있으면 키보드만 닫기 → 변경 있으면 D-02, 없으면 S-10

## S-13 연결 코드 입력 · 보호대상자 · FR-01
- route `protected/code`. 앱바 “보호자와 연결” + ←. 보호대상자 화면은 본문 18sp
- “보호자 화면에 보이는 6자리 코드를 입력하세요”, 6칸(3+3)이지만 **입력 필드는 하나**(숫자 키패드), “코드는 발급 후 10분 동안 쓸 수 있습니다.”

- 오류: 칸 테두리 굵게 + 아이콘 + “코드가 맞지 않거나 만료되었습니다. 보호자 화면의 코드를 다시 확인하세요.” 입력값 유지
- 뒤로: 키패드 닫기 → S-01 (확인 없음)

## S-14 연결 동의 · 보호대상자 · FR-01
- route `protected/consent`. 앱바 “연결 동의” + ←
- “보호자가 위치 확인을 요청했습니다”, 카드: 제공 정보 “위치 좌표, 수집 시각” / 수집 주기 “약 30초마다” / 볼 수 있는 사람 “연결된 보호자 1명” / 연결 해제 “언제든 [연결 관리]에서”. 문구 “건강 정보·연락처는 수집하지 않습니다.”
- [동의하고 연결](56dp) → link 생성 → S-15 / [거부] → code `denied` → S-01
- 뒤로: S-13 (요청은 거부·만료 전까지 유지)

## S-15 위치 권한 안내 · 보호대상자 · NFR-05, FR-02
- route `protected/permission`. “위치 권한이 필요합니다 / 화면이 꺼져 있어도 위치를 기록하려면 위치 권한을 항상 허용으로 설정해야 합니다.”
- 단계: “1 [앱 사용 중에만 허용] 누르기”, “2 설정 화면에서 [항상 허용] 고르기”. [권한 허용하기] → 전경 위치 권한 요청 → 백그라운드 권한(설정 화면) → 알림 권한
- [나중에 하기] + “허용하기 전에는 위치를 기록하지 않습니다.”
- 허용 완료 → S-16(기록 시작). 뒤로 → S-16 권한 없음 상태(수집 안 함, A2)

## S-16 위치 기록 (보호대상자 홈) · FR-02, FR-06, NFR-05
- route `protected/home`. 앱바 “위치 기록” + ⚙(→ S-12). 진행 알림 탭으로도 진입
- 큰 원 아이콘 + **“기록 중”**(24sp) + “마지막 수집 14:32”
- 행: “서버 전송 모두 전송됨” → S-17, “연결된 보호자 1명”
- 문구 “화면을 꺼도 약 30초마다 위치가 기록됩니다. 상단 알림 표시줄에 ‘위치 기록 중’이 계속 표시됩니다.”
- 상태
  - 로딩: 점선 원 + 진행 표시 “위치를 찾는 중 / 첫 위치를 받으면 기록이 시작됩니다”
  - 비어 있음(연결 없음): “위치를 기록하지 않습니다 / 연결된 보호자가 없습니다. 보호자와 연결하면 기록이 시작됩니다.” [보호자와 연결] → S-13
  - 오류 · 권한 없음(A2): “위치를 기록할 수 없습니다 / 원인: 위치 권한이 ‘허용 안 함’입니다 / 마지막 정상 수집: 오늘 11:20” [권한 설정하기] → S-15
  - 오류 · 위치 서비스 꺼짐: “원인: 휴대폰 위치(GPS)가 꺼져 있습니다” [위치 켜기]
  - 오류 · 저장 공간 부족: “기록을 멈췄습니다 / 원인: 휴대폰 저장 공간이 부족합니다 / 저장된 기록 1,240건은 보관 중입니다.” [저장 공간 확인]
  - 부분 · 오프라인(A3): 배너 “인터넷 연결 없음 · 기록은 휴대폰에 저장 중”, 행 “서버 전송 대기 23건”
- 상태 변화(권한·서비스)는 `links.permission`에 보고(온라인일 때)
- 뒤로: 앱 백그라운드(기록 계속)

## S-17 전송 상태 · 보호대상자 · FR-06, NFR-03
- route `protected/sync`. 앱바 “전송 상태” + ←
- 기본: 카드 “전송 대기 0건 / 오늘 전송 412건 / 마지막 전송 14:32”, “오늘 전송 기록” 시간대별 행(“14:00 ~ 14:32 · 64건”)
- 로딩: “전송 중 12 / 23” + 진행 막대 + “전송된 기록은 다시 보내지 않습니다.”
- 비어 있음: “오늘 수집한 기록이 없습니다 / 위치 기록이 시작되면 전송 상태가 여기에 표시됩니다.”
- 오류: “전송하지 못했습니다 / 원인: 서버가 응답하지 않습니다 (10초 초과) / 기록 23건은 이 휴대폰에 그대로 보관 중입니다. 1분 뒤 자동으로 다시 시도합니다.” [지금 다시 시도]
- 부분 · 오프라인: 배너 “인터넷 연결 없음 · 미전송 23건 대기 / 연결되면 자동 전송, 같은 기록은 한 번만 보냅니다”, “전송 대기” 그룹 + “오늘 전송 기록” 그룹
- 뒤로: S-16
